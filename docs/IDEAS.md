# Writing an idea

A `.kuron` file is an idea in words. There is no grammar: one line is enough, and a longer description simply gives the
setup agent more to go on. Write in any language; the system speaks the language you use.

Helpful things to say, if you know them:

- who uses it and on which devices (a reception tablet, the doctor's PC, the patient's phone, a waiting-room display, an IoT box)
- what it must remember (patients, orders, readings…) and whether it should start with sample data
- what people do (register, call the next one, take a picture…) and what the system should judge or generate
- what touches the real world (camera, microphone, earphones, speaking, drawings) and what test situation to prepare
- how you will know it works (a few scenarios)

The examples in `examples/` were written as structured design documents for an earlier version; they still work as ideas.
