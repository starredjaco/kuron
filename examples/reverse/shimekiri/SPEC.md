# 締め切り番 — specification from a running Kuron prototype

タスクを入れると、締め切りと中身から今日やるべき順に並べ、やり忘れそうなものを先回りして教えてくれる

## State

```json
{
  "type": "object",
  "properties": {
    "タスク": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "名前": {
            "type": "string"
          },
          "締め切り": {
            "type": "string"
          },
          "優先度": {
            "type": "string"
          },
          "優先度の理由": {
            "type": "string"
          },
          "済み": {
            "type": "boolean"
          },
          "ひとこと助言": {
            "type": "string"
          }
        },
        "required": [
          "名前",
          "締め切り",
          "優先度",
          "優先度の理由",
          "済み",
          "ひとこと助言"
        ]
      }
    },
    "今日の方針": {
      "type": "string"
    }
  },
  "required": [
    "タスク",
    "今日の方針"
  ]
}
```

- **タスク** (records) — 名前・締め切り・優先度（高/中/低）・優先度の理由・済み・ひとこと助言 を持つ一覧
- **今日の方針** (text) — 残っているタスク全体を見た、今日の進め方の一文

Initial value:

```json
{
  "タスク": [],
  "今日の方針": ""
}
```

## Screens

### 一覧 (サイト)

- heading · "今日やること"
- text · "{今日の方針}"
- input · input タスク名 (text)
- input · input 締め切り (text)
- button · "追加" · → action 追加
- list · from タスク
  - row: text · "{名前}"
  - row: text · "{締め切り}"
  - row: badge · "{優先度}"
  - row: text · "{優先度の理由}"
  - row: text · "{ひとこと助言}"
  - row: button · "済み" · → action 済み
- metric · label "済みのタスクの数" · from タスク
  - row: text · "{count:タスク}"

## Actions

### 追加

reads: タスク, 今日の方針 · writes: タスク, 今日の方針 · inputs: タスク名, 締め切り

1. 入力された「タスク名」と「締め切り」を新しいタスクの「名前」と「締め切り」に設定する
2. 新しいタスクの「名前」と「締め切り」を基に、優先度（高・中・低）を決定する
3. 決定した優先度の理由を一文で「優先度の理由」に記述する
4. 新しいタスクの「名前」と「締め切り」を基に、やり忘れを防ぐ「ひとこと助言」を記述する
5. 新しいタスクの「済み」を false に設定する
6. 作成した新しいタスクを「タスク」一覧に追加する
7. 「タスク」一覧全体を確認し、今日の進め方を一文で「今日の方針」に書き直す

## Checks

- 「請求書を送る（今日）」と「本を読む（来月）」を追加すると、請求書を送るの優先度が本を読むより高くなる
  - expect: タスク一覧に「請求書を送る（今日）」と「本を読む（来月）」の2件が存在する。
  - expect: 「請求書を送る（今日）」の優先度が「本を読む（来月）」の優先度より高い。
- タスクを1つ追加すると、そのタスクの優先度の理由が空でない一文になっている
  - expect: タスク一覧に「レポート作成」というタスクが追加されている
  - expect: 追加されたタスクの「優先度の理由」が空ではなく、一文で記述されている
- タスクを1つ追加して済みにすると、そのタスクは済みになる
  - expect: タスク一覧に「レポート作成」というタスクが存在する
  - expect: 「レポート作成」のタスクの「済み」はtrueである
  - expect: 今日の方針が更新されている

## Original Kuron program

```
# システム: 締め切り番
説明: タスクを入れると、締め切りと中身から今日やるべき順に並べ、やり忘れそうなものを先回りして教えてくれる
形: サイト

## 状態
- タスク: 名前・締め切り・優先度（高/中/低）・優先度の理由・済み・ひとこと助言 を持つ一覧
- 今日の方針: 残っているタスク全体を見た、今日の進め方の一文

## 画面 一覧
- 見出し「今日やること」と今日の方針
- タスク名と締め切りの入力欄、「追加」ボタン
- 済みでないタスクを優先度の高い順に表示。各行に名前・締め切り・優先度の印・優先度の理由・ひとこと助言・「済み」ボタン
- 済みのタスクの数

## 動き
### 追加
- 入力された名前と締め切りで新しいタスクを作る
- 中身と締め切りから優先度（高・中・低）を決め、その優先度にした理由を一文で優先度の理由に書く
- やり忘れを防ぐひとこと助言を書く
- 今日の方針を、残りのタスク全体を見て書き直す

### 済み
- 選んだタスクを済みにする
- 今日の方針を書き直す

## 確かめる
- 「請求書を送る（今日）」と「本を読む（来月）」を追加すると、請求書を送るの優先度が本を読むより高くなる
- タスクを1つ追加すると、そのタスクの優先度の理由が空でない一文になっている
- タスクを1つ追加して済みにすると、そのタスクは済みになる
```
